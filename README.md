# API списка задач на Node.js и Express

Учебное серверное приложение. Данные хранятся в памяти и очищаются при перезапуске.

## Запуск

Установите Node.js версии 18 или выше. В каталоге проекта выполните `npm install`, затем `npm start`. Адрес сервера — `http://127.0.0.1:3000`.

## Маршруты

| Метод и путь | Операция | Успешный статус |
| --- | --- | --- |
| GET /api/health | Проверка сервера | 200 |
| GET /api/tasks | Список задач | 200 |
| POST /api/tasks | Создание задачи | 201 |
| GET /api/tasks/:id | Получение задачи | 200 |
| PUT /api/tasks/:id | Замена полей задачи | 200 |
| DELETE /api/tasks/:id | Удаление задачи | 204 |

POST принимает объект с полем `title` и необязательным логическим полем `completed`. PUT требует оба поля. Передавайте тело с заголовком `Content-Type: application/json`.

`src/server.js` запускает HTTP-сервер. `src/app.js` подключает журналирование, JSON-парсер, маршруты и обработчики ошибок. `src/routes/tasks.js` определяет маршруты и проверяет входные данные.

## Postman

Импортируйте `postman/tasks.postman_collection.json` и запустите коллекцию целиком через Collection Runner при работающем сервере. Коллекция сохраняет ID созданной задачи и проверяет успешные ответы, ошибки валидации, повреждённый JSON и запрос удалённой задачи.
